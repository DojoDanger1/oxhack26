## BLUNDOMETER

The blundometer is a chrome extension for lichess.org, which adds a blundometer for each player on games which you are spectating.

## Installation
1. Navigate to `chrome://extensions`
2. Enable developer mode
3. Press Load Unpacked and select the folder `blundometer-extension`

The blundometer will now appear on any page of the format `lichess.org/games/*`!
